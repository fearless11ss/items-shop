# Contributing to Items Shop

## Bug reports

Use the bug report form in GitHub Issues. Include exact reproduction steps and the versions of Items Shop, Minecraft, and Forge. Attach `latest.log` or a crash report when relevant, but remove access tokens, server addresses, and other private information first.

## Pull requests

Keep each pull request focused on one change. Explain the problem being solved, describe the implementation, and report how the change was tested. Economy changes should include concrete before-and-after price examples and an explanation of how crafting or trading loops were considered.

By contributing, you agree that your contribution may be distributed under the project's MIT License.
